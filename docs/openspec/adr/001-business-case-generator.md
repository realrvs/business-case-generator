# ADR-001: Генератор бизнес-кейсов

## Статус
Принято

## Контекст
Необходимо автоматизировать создание бизнес-кейсов для AI-проектов.

## Решение
Использовать RAG + YandexGPT для генерации структурированных отчетов.

## Аргументы за
- Быстрая генерация
- Единообразие
- Интерактивность

## Аргументы против
- Зависимость от RAG
- Зависимость от YandexGPT

## Последствия
- Нужна индексация финансовых данных
- Важно качество промптов
